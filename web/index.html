Play tracking filter

Which plays this profile records at all. A play this filter turns away is not saved anywhere — no score, no pp, no play count — and it cannot be brought back afterwards, so switch the filter off before importing past plays you want in regardless.

Off by default, and every play is tracked. Turning it on changes nothing on its own: every criterion below starts wide open.

Two criteria cannot judge a play that was quit, failed or retried: osu!lazer records no mods and no star rating for a play it discards, so those plays are matched on the other seven. That is deliberate — osu! counts them, so this does.

 

Other settings

Removed scores0

Removing a score, or a play that was not finished or submitted, never deletes it. Put one back and it returns to every section and to the totals. The red minus deletes one for good: it cannot be put back, and it is never imported again.

Profiles

Each profile is a separate playstyle with its own scores, pp and level. Only the selected one records the plays you set.

A new profile starts empty and tracks from the moment you create it.

Edit profile

The name, flag, playstyle, picture and banner for this profile, the one being tracked. None of this is required — a new profile starts with a drawn avatar and the cover art of its best play.

Two-letter code, shown beside the profile name. Leave empty for none.

Reset this profile
Erases everything tracked for this profile and starts it again from zero. It asks first, and your osu! account and replay files are not touched.

Import from osu!

Copies what you choose from an osu! account's public profile into this profile, and links the two. Nothing is ever written to osu!.

One request to osu.ppy.sh to find the account, one per picture, and one per hundred favorites -- all when you press Import. No login and no API key.

 

Every profile

On by default: one list, shared by every profile. Turn it off and each profile keeps its own copy of the list as it stands; turn it back on and the lists are merged. Nothing is lost either way.

Import past plays

Plays set while this app was closed were never tracked. Choose how far back to look and they will be imported from that moment onward — finished plays from their replays, and quits, fails and retries from osu!lazer’s own logs.

Go back only as far as the session you played with this playstyle. Anything earlier pulls in plays set with your normal one — which is exactly what a separate profile exists to keep out.
Pick a time, then check what would be imported.

Reset this profile?

This erases everything tracked so far and starts from zero.

This cannot be undone. Replays stay on disk, but they will not be re-imported: tracking restarts from the moment you confirm.
  • All tracked scores are deleted
  • pp, rank, accuracy, level and play count return to zero
  • Your osu! account and your replay files are not touched

Update available

Your tracked scores, settings and profile pictures are kept — they live in data/, which an update never touches. The files being replaced are set aside until the new version is in place, so an update that is interrupted can be undone rather than leaving a half-installed app.
