Import from osu!

Copies what you choose from an osu! account's public profile into this profile, and links the two. Nothing is ever written to osu!.

To import scores from your osu! client, go to Options → Import past plays.

One request to osu.ppy.sh to find the account, one per picture, one per hundred favorites, and a few per game mode for scores, no login and no API key needed.

Import past plays

Import plays from osu! client, including from before this app was installed.

To import scores from your online osu! profile, go to Options → Profiles.

Every play osu! has kept on this computer, however old. Checking reads every replay, so it can take a while, and importing thousands of plays takes minutes.

Import from a score link

Paste a score's link from osu.ppy.sh - for a play whose replay you no longer have. Its pp is calculated here from the score's own numbers, exactly as osu! calculates it, and recalculated here after a pp rework with no internet needed.

Paste a link, then check it.

Enter a score by hand

A last resort, for a play with no replay and no score link. Nothing can check what you type, so the score is marked "Manually entered by hand" everywhere it appears, shared copies included. Its pp is calculated from the numbers you enter.

 

Reset this profile?

This erases everything tracked so far and starts from zero.

This cannot be undone. Replays stay on disk, but they will not be re-imported: tracking restarts from the moment you confirm.
  • All tracked scores are deleted
  • pp, rank, accuracy, level and play count return to zero
  • Your osu! account and your replay files are not touched

Update available

Your tracked scores, settings and profile pictures are kept - they live in data/, which an update never touches. The files being replaced are set aside until the new version is in place, so an update that is interrupted can be undone rather than leaving a half-installed app.

To have new versions installed by themselves, turn on Options → Auto-update.
